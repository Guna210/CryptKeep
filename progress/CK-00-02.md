The canvas is full viewport and its drawing buffer tracks resize; the root starts with an initializing status and shows a readable compatibility message if WebGL 2 cannot be acquired. `ShellOptions.getWebGL2Context` provides a narrow capability seam for browser tests. It is not exposed through a URL flag or production query behavior. CK-00-03 can attach its renderer to the returned canvas and own its renderer lifecycle.
