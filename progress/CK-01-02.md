## Scope and result

Implemented pure, bounded seeded placement for room rectangles in a valid empty `FloorPlan`. The module only places room interiors and assigns IDs; it does not add corridors, roles, rendering, retry orchestration, or fallback generation.

Changed paths: `src/dungeon/rooms.ts`, `src/dungeon/rooms.test.ts`, and this handoff. No other files were intentionally changed.

## Exported contracts

- `layoutDefaults(floorNumber)` validates floors 1–100 and returns a frozen record with square dimensions `min(80, 36 + 4 * floorTier)` and room count `min(18, 7 + floor((floorNumber - 1) / 8))`.
- `placeRooms(plan, options?)` accepts only a plan with no rooms and all-solid tile occupancy. It rejects malformed placement options, existing rooms, or pre-carved tiles before sampling. Supported controls are `targetRoomCount` (1–18, default floor formula), `minRoomSize` / `maxRoomSize` (inclusive 5–12, defaults 5/12), `clearance` (1–4 solid cells, default 1), `border` (1–4 solid cells, default 1), and `maxAttempts` (0–4096 total candidate attempts, default 1024). Unknown controls reject.
- At entry, the supplied plan is reconstructed through `createFloorPlan`; dimensions, tile lengths/values, rooms, seed, and nested records are validated and detached before preconditions or RNG derivation.
- Candidate dimensions and origins use the local `layout` stream derived from the floor seed, generator version, floor number, and `rooms` source. Room IDs use `stableId(floorSeed, floorNumber, "room", acceptedOrdinal)`; rejected candidates do not consume ordinals.
- The returned frozen `{ plan, requestedRoomCount, attempts, complete }` contains detached frozen records and carved room interiors. `attempts` counts all sampled candidates, including rejected ones. A valid but impossible or budget-exhausted request returns its partial plan with `complete: false`; if the minimum room cannot fit with the border, it returns immediately with zero attempts. No limits are relaxed.
- Rooms stay within the solid outer border. A pair is accepted only if there is at least the requested number of solid cells between their half-open rectangles on at least one axis, so touching edges and diagonal corner contact are rejected at the default clearance.
