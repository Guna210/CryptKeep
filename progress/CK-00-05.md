## Exported contracts

- `normalizeSeed(seed)` accepts only strings, trims and NFC-normalizes, permits the empty result, and limits the normalized result to 64 Unicode code points (`[...string].length`, so astral characters count once). Lone UTF-16 surrogates remain in the normalized value; UTF-8 `TextEncoder` maps each to U+FFFD deterministically.
- `fnv1aUtf8(value)` computes 32-bit FNV-1a over UTF-8 bytes.
- `deriveStream(seed, domain, source = "root")` derives an independent named stream using canonical JSON-array component boundaries. Seed length/normalization rules apply; domain/source must be nonempty strings and are NFC-normalized.
- `SeededRng` provides `nextUint32()`, `nextFloat()` in `[0, 1)`, `nextInt(minInclusive, maxExclusive)` using rejection sampling for an unbiased result, `snapshot()`, and strict `restore(cursor)`. Snapshots are plain `{ algorithm, state }` values with four unsigned words; restore rejects malformed shape, unsupported algorithms and all-zero state. Copies do not share mutable state.
- `stableId(seed, floor, domain, spawnOrdinal)` returns a stable string whose JSON tuple encoding prevents collisions across component boundaries. Floor is an integer 1–100; ordinal is a nonnegative safe integer; domain is a nonempty NFC-normalized string.

Stream derivation uses FNV-1a starting at `0x811c9dc5`, multiplying by `0x01000193` modulo 2^32 for each UTF-8 byte. Each xoshiro state word hashes the canonical tuple `[JSON([normalizedSeed, domain, source]), "cryptkeep-rng-v1", wordIndex]`. The version component permits a future derivation change without silently reusing this mapping. xoshiro128** uses the published reference transition and rejects the all-zero state (defensively replacing it during derivation). Intended named domains include `layout`, `roomroles`, `encounters`, `enemy`, `boss`, `containers`, `enemyloot`, `combat`, and the isolated `cosmetics` domain.

The reference xoshiro128** vector uses initial state `[1,2,3,4]`; its first six outputs are `11520, 0, 5927040, 70819200, 2031721883, 1637235492`. Each transition applies the reference sequential updates: `s2 ^= s0; s3 ^= s1; s1 ^= s2; s0 ^= s3; s2 ^= t; s3 = rotl(s3, 11)`. FNV-1a UTF-8 vectors include empty input `0x811c9dc5`, `hello` `0x4f9f2cab`, and `é` `513665217`.
