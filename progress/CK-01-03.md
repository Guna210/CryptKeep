## Scope and result

Added a pure seeded room-connection pass that returns a detached immutable `ConnectedFloorPlan`. It computes a deterministic minimum spanning tree over canonical room pairs, carves a two-cell orthogonal L route for each tree edge, then attempts bounded optional loops. Optional edges are recorded only when their route adds walkable cells. Existing room tiles are preserved. No app wiring, roles, retries, fallback, or renderer changes were made.

Owned changes: `src/dungeon/corridors.ts`, `src/dungeon/corridors.test.ts`, `progress/CK-01-03.md`, and the assigned evidence file `docs/evidence/CK-01-03/map.txt`. The concurrent `CONTEXT.md` edit is owner work and was not changed.

## API and deterministic rules

- `connectRooms(plan, options?)` accepts an accepted `FloorPlan` and returns `ConnectedFloorPlan extends FloorPlan` with readonly `edges`.
- `CorridorOptions` supports only `loopFraction`, a finite number in `[0,1]`, default `0.2`. Unknown or malformed options reject before RNG derivation and carving; only an omitted/`undefined` fraction selects the default, while explicit `null`, strings, `NaN`, and infinities reject. Input is first reconstructed through `createFloorPlan` to detach and validate it.
- Plans with no more than 18 rooms are supported. Rectangles must not overlap, each must be at least 2×2, and every room-interior tile must already be walkable. Empty and one-room plans return no edges.
- Room IDs use explicit UTF-16/code-unit ordering. Complete canonical room pairs are ordered by squared center distance then IDs; Kruskal produces exactly `n-1` tree edges. Centerline endpoints are centered 2×2 anchors wholly within their named rooms.
- An isolated `deriveStream(floorSeed, "layout", JSON.stringify([generatorVersion, floorNumber, "corridors"]))` selects tree bends, loop candidate order, and loop bends. Tree carving precedes loops, so `loopFraction: 0` preserves tree routes.
- Every path is an ordered cardinal centerline. Each anchor carves its 2×2 footprint, bounded by the floor dimensions. The copied tile array and all edge/path/point records are frozen; the output remains plain JSON-serializable data.
- Requested optional edge count is `min(nonTreePairs, ceil((n-1)*f/(1-f)))` for `f < 1`; `f=1` tries all pairs. Actual overlap can reduce the achieved count; fully overlapping paths do not create graph-only edges.
