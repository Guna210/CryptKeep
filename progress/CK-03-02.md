## Result and interface

Added a pure TypeScript query in `src/combat/queries.ts`, with geometry fixtures in `src/combat/queries.test.ts`. `queryMeleeTargets(input)` accepts a horizontal origin, Three.js yaw in radians, immutable `Grid`, target circle colliders (`id`, X/Z position, finite nonnegative radius), and optional reach/arc width. Omitted reach and arc default to 2 meters and 90 degrees. Arc width is the full horizontal width, from 0 to 2π. Invalid query-level geometry returns an empty frozen result; invalid individual colliders are skipped.

The geometric rule is contact-point based: a target circle is in range and arc if any part of it intersects both. The query forms the circle's tangent-bearing interval, clips it to attack arc and reach only when reach excludes first-contact rays, and partitions it at the center bearing, interval endpoints, solid-tile corner bearings, and intersections between the collider circle and solid tile edges. It checks each partition boundary and one midpoint per open interval, computes the exact near circle contact on each ray, then applies exact reach, arc and segment LOS checks. This finds exposed portions when the nearest contact is blocked and accounts for a collider overlapping a wall. The query selects the nearest among its verified generated candidates; it does not claim a globally nearest visible point when visibility boundaries are open. Critical angles are normalized around the target bearing, including for wrapped/full-circle arcs.

Yaw follows Three.js: yaw 0 faces -Z and positive yaw turns toward -X. LOS checks segment intersection against the actual 2m square rectangles of solid grid cells, including tangency/corner contact. Any segment extending outside the grid rectangle is blocked as out-of-map space. The scan is bounded by the grid's maximum 80×80 cells. Results are frozen, deduplicated by target ID even when duplicate colliders occur in the input list, and sorted by ID; if duplicate IDs provide multiple eligible colliders, the nearest visible candidate is retained. A caller can use each result as one target hit for its attack and apply damage through the CK-03-01 resolver.

No sword attack implementation, dispatcher, event wiring, Three.js, DOM, randomness, or damage application was added.
