## Exported contract

`verificationStages` exports the ordered stage descriptors. `runStages(stages, options)` exports a small runner taking `{name, command, args}` descriptors and optional `cwd`, `spawn`, and `output` dependencies. It resolves to zero only when every stage exits zero; any spawn error, nonzero result, or terminating signal stops later work and returns nonzero. Importing the module has no side effects; direct execution runs the repository stages.
