The Playwright harness now attaches page-error and `console.error` listeners before navigation, waits for the shell status to become ready or report unsupported WebGL 2, returns captured messages for assertions, and removes its listeners after each test. A routed temporary negative-control page emits a real browser `console.error` and an uncaught asynchronous exception; the test confirms both are captured and that the harness failure report names them.

Development builds expose `window.__cryptkeepDiagnostics.snapshot()`. It reports readiness (`initializing`, `ready`, or `unsupported`) and a detached, frozen renderer-count object. Main owns installation and removes the property on `pagehide`. Unsupported WebGL 2 remains reported as unsupported. Vite's production build removes the dev-only installer and global; the production browser check also visits with diagnostic-looking query parameters and confirms no global exists.

The browser suite has a development project that discovers normal Playwright specs while excluding only the production-only spec, plus a production project served from `dist/` on a separate Vite preview port. `npm run test:e2e` runs `npm run build` before Playwright, so it is self-contained from a clean `dist/` and incurs a build even if one was run immediately beforehand. Existing renderer lifecycle and unsupported-WebGL coverage remains intact.
