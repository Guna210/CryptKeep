## Exported contracts

- `Tile.Solid` is `0`; `Tile.Walkable` is `1`. Grids contain positive integer dimensions up to 80×80 and a copied/frozen plain tile array in row-major `z * width + x` order.
- `createGrid(width, height, tiles)` validates dimensions, length, and tile values, then returns a detached frozen `Grid`.
- `isInBounds(grid, cell)` validates integral safe-integer cell coordinates and reports grid bounds. `cellIndex` returns row-major index or `null`; `tileAt` returns the tile or `null`; `isWalkable` returns false outside bounds.
- `orthogonalNeighbors` returns a frozen list bounded to the grid in the documented order +X (east), −X (west), +Z (south), −Z (north).
- `worldToCell({x,z})` uses `Math.floor` at 2-meter cell size, including for negative coordinates. World inputs must be finite and map to safe integer cell coordinates. `cellToWorld(cell)` returns cell centers, including for negative integer cells.
- `createRoomRect(x,z,width,height)` creates validated frozen half-open integer bounds. `createRoom(id,rect)` trims and validates a nonempty ID and copies the rectangle.
- `createFloorPlan(input)` creates only `floorNumber`, normalized `floorSeed`, `generatorVersion`, `width`, `height`, `tiles`, and `rooms`. Floors are integers 1–100; the documented default generator version is `cryptkeep-layout-v1`; rooms default to empty. It validates dimensions, occupancy, unique nonempty IDs and in-grid room bounds, then copies/freezes every nested record and array.

Builders for later tasks can copy `grid.tiles` into a mutable local array and pass that array to `createGrid` or `createFloorPlan`; the returned record is detached and frozen.
