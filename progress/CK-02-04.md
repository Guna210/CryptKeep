# CK-02-04 — Implement mouse look and pointer capture

**Builder/model:** `/root/ck_02_04_builder` / GPT-6 Luna
**Status:** **SUBMITTED** for independent review; not yet accepted.

## Result and scope

Added pure mouse-look math and a browser pointer-capture adapter. The adapter owns pointer lock for one gameplay surface, accepts capture only through an explicit `requestFromGesture()` call (the caller must invoke it synchronously from a trusted click/Resume handler), forwards captured relative mouse deltas to the accepted `InputSampler`, and cancels input on Escape, blur, hidden document, lock loss, denied capture, or disposal. It does not synthesize ordinary release edges. A small isolated fixture proves native Chromium pointer lock without wiring the app before CK-02-05.

Changed paths: `src/player/look.ts`, `src/player/look.test.ts`, `src/app/pointer-capture.ts`, `tests/harness/pointer-capture.html`, `tests/harness/pointer-capture.ts`, `tests/e2e/pointer-capture.spec.ts`, and this handoff. No app composition or Git mutation was performed.

## Interfaces and behavior

- `applyMouseLook(pose, delta, settings?)` applies the default 0.002 radians/pixel sensitivity. Positive Three.js yaw looks left, so moving the mouse right decreases yaw. Moving the mouse upward increases pitch. Yaw is not wrapped or clamped; pitch is clamped to ±85°. Optional sensitivity and invert-Y settings are supported. Nonfinite pose/delta/settings arithmetic is guarded.
- `createPointerCapture(surface, sampler, options?)` returns a `PointerCapture`. Call `requestFromGesture()` only from a trusted user gesture. States are `idle`, `requesting`, `captured`, `failed`, and `disposed`; an optional state observer receives cancellation/denial reasons. Observer exceptions cannot block input clearing or owned-lock release.
- The adapter only releases pointer lock while `document.pointerLockElement === surface`. It handles modern promise requests and legacy void requests, request rejection/error, late acquisition after cancellation/disposal, native lock changes, Escape, blur, hidden page, mouse movement, and context-menu suppression on its owned surface. Retry after failure requires another explicit call from a gesture.
- The harness exposes test-only state and sampling controls. It does not alter application composition or expose any production diagnostic API.

The browser denial branch is intentionally simulated because the browser cannot reliably deny this local test's trusted pointer-lock request.
