**Builder/model:** `/root/ck_02_05_builder` / GPT-6 Luna
**Status:** **SUBMITTED** for independent review. No Git operations were performed.

## Result

Added one app-lifetime `PlayerSession` that owns keyboard/mouse actions and one serialized pointer-capture adapter across floor rerolls. A successful `load(seed)` consumes the existing `FloorSession.load` result and resets player state to the generated entry cell. The floor clock stays paused until an explicit Explore gesture captures the canvas; capture loss, Escape, blur, hidden page, failed capture, lock loss, and disposal clear input and stop velocity. Focus and visibility restoration do not resume play automatically.

At each available fixed tick the session consumes one `InputSampler` snapshot, applies transient look, advances normalized yaw-relative 3.5 m/s walking, resolves the requested displacement with the accepted swept-circle collision algorithm against the generated immutable plan, and commits the corrected pose and velocity. The camera uses interpolated presentation poses at a fixed 1.6 m eye height without feeding interpolation back into simulation. The main floor factory enables its accepted 3 m indoor ceiling option; the shared overview/harness default remains unchanged.

The shell has an accessible Explore button and concise WASD/mouse/Escape help. Development diagnostics include a detached, frozen player snapshot. README and startup instructions now describe the movement slice and its current limits.
