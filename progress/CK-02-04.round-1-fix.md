## Changes

Added a monotonically increasing request generation. Promise callbacks settle state only while their request remains current. Late obsolete rejections cannot fail the newer gesture attempt, and late obsolete resolutions cannot clear its pending state. A stale successful request releases the surface only if the adapter still owns a lock that has not been attributed to a newer captured generation. Pointer-lock change events associate acquisition with the active generation.

Disposal now distinguishes a pending legacy `void` request from a modern promise request. Normal disposal removes every listener immediately. When a legacy request is still pending and does not yet own the lock, disposal removes visibility, blur, key, mousemove, and context-menu listeners while retaining only document `pointerlockchange` and `pointerlockerror` guards. A late owned acquisition is released and the guards remove themselves; a late lock error also removes them. Unrelated lock changes leave the guards in place until that request settles. The disposed instance stays disposed, never notifies/reactivates, and ignores new gesture requests/input.

Added `src/app/pointer-capture.test.ts` with deterministic controlled-promise reproductions for A → cancel → B → stale A resolve/reject → B resolve, plus legacy-void disposal followed by late acquisition/error. The tests assert pending-attempt preservation, observer state after disposal, no post-disposal movement input, immediate ordinary-listener cleanup, retained terminal guard count, owned-lock release, and terminal guard removal. No app composition, unrelated task, or Git operation was performed.
